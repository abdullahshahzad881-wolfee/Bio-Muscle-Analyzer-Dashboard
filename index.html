Growth interpretation guide
iEMG increasing (>5% WoW)
Progressive overload confirmed. Hypertrophy stimulus present. Continue current program.
iEMG plateau (±5% WoW)
Muscle adapted to stimulus. Increase load, volume, or tempo.
iEMG dropping (<-5% WoW)
Possible overtraining or underrecovery. 48h rest recommended before next session.

Validation test protocol
Test 1 — Baseline rest
Sit completely relaxed 60s. Expected RMS: 5–20 µV
Test 2 — Max voluntary contraction (MVC)
Squeeze bicep maximally 5s. Expected RMS: 500–2000 µV
Test 3 — Mental arithmetic stress
Count backwards from 300 by 7. Expected RMS rise: +20–80 µV
Test 4 — Fatigue protocol
Repeated contractions to failure. Expected MDF drop: 15–30 Hz
