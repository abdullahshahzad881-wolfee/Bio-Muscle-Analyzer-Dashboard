How to test the system
1 — Rest test
Sit completely relaxed for 60 seconds. Muscle activation should read below 20 µV.
2 — Max flex test
Flex bicep as hard as possible for 5 seconds. Activation should reach 500–2000 µV.
3 — Fatigue test
Do repeated curls until tired. Fatigue level should rise toward 70%+.
Medical sources used
De Luca (1997)
Established muscle activation reference ranges used in clinical EMG. Used for RMS and fatigue values.
Konrad (2005)
Standard guide for surface EMG signals. Used for muscle activity level ranges.
Lundberg (2002)
Posture and stress research. Used for arm angle thresholds and shoulder elevation standards.
